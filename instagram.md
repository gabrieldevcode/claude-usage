# Post do Instagram — Claude Usage Stick

## Legenda

🦀📟 Claude Usage Stick — meu medidor de uso do Claude Code em tempo real, direto na mesa!

Uma tela touch de 3,5" (ESP32-S3) mostrando quanto das janelas de 5h e da semana eu já queimei: contagem regressiva do reset, projeção de quando a sessão esgota, tokens gastos e os mascotes Clawd em pixel-art reagindo ao status de cada modelo — piscando quando está tudo bem, suando quando o limite aperta. 😅

A cada 25/50/70/100% de uso, uma animação toma a tela pra avisar. Firmware em C com LVGL, dados direto da API da Anthropic, interface em PT/EN — e desenvolvido com o próprio Claude Code, claro. 🤝
